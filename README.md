# 🪷 FEHIZORO — Software Developer & Designer Portfolio

Bienvenue sur le dépôt de mon portfolio professionnel. Ce projet est une fusion entre la **rigueur du développement logiciel** et l'**esthétique du design digital/3D**. 

L'identité visuelle est centrée sur le symbole du **Lotus**, représentant l'évolution et la clarté technique.

## technologies utilisées

### Frontend (Interface)
* **React.js** (Vite)
* **Tailwind CSS** (Design & Responsive)
* **Lucide React** (Iconographie)
* **Framer Motion** (Animations fluides)

### Backend (Logique & API)
* **Django** (Python)
* **Django Rest Framework** (API pour les projets et compétences)
* **CORS Headers** (Sécurité des échanges)

## ✨ Fonctionnalités clés

* **Design Glassmorphism** : Cartes de projets translucides avec effet de flou arrière (`backdrop-blur`).
* **Gestion Dynamique** : Les projets et les compétences sont récupérés en temps réel via l'API Django.
* **Formulaire de Contact** : Système d'envoi de messages avec stockage en base de données et notification par mail.
* **Expérience Immersive** : Background animé avec un Lotus central en haute définition.
